# 华文／英文界面

系统支持 `cn`（简体华文）与 `en`（英文）。首次使用默认华文；语言选择保存在浏览器的 `i18nextLng` 中。旧版英文地区代码归一为英文，其他旧语言回退华文。储存不可用时使用内存状态。

后台页头及其他页面的右下角提供「华文 / English」入口。切换不会刷新路由或重置个案表单。分页、日期选择器、日历、系统通知和表单错误同步更新。

## 维护文案

- `src/locales/messages.json` 是界面文案的唯一双语资源表，每项同时包含 `cn` 和 `en`。插值参数必须一致。
- 使用 `tr('Authored UI text', { p0: value })` 渲染系统文字，并在组件中使用 `useUiLanguage()` 订阅语言变化。需要缓存的已翻译结果应以语言为依赖。
- 旧模板的导航及演示文案继续使用 `src/locales/langs/en.js` 和 `cn.js`。
- 只在显示时通过 `domainLabel` 翻译内置类别、辅导类型和状态。数据库值、筛选值、姓名、用户输入和记录正文不变。示例人名、影片名、品牌和代码标识保留原文。
- 已保存的系统错误可用 `uiMessage` 显示；不要将记录正文交给这个函数。

## AI 兼容

`POST /api/ai/case-advice` 与 `POST /api/ai/management-insights` 的 `latest`、`generate` 请求接受可选 `language`，仅允许 `cn`、`en`；未传时默认 `cn`。

语言纳入缓存范围和现有 `filter_snapshot`，无需数据库迁移。JSON 字段、枚举与来源引用不翻译。旧版无语言标记的缓存作为 `legacy: true` 返回，界面保留原文并显示过期提示。切换语言只读取缓存，不自动生成；取消的旧请求不能更新当前结果。

```sh
npm run build
```

本次环境没有可连接的浏览器。发布前仍需在桌面与手机浏览器巡查可访问页面，确认长英文按钮、弹窗、图表图例和右下角切换入口无遮挡；验证真实 AI 服务的输出语言。自动测试使用模拟服务，不调用付费模型。
