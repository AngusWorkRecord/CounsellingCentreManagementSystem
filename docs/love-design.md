# 爱情设计卡 / Love Design

运行 `npm start` 后访问 `/love-design`。这是无需登录的自由牌桌，不包含活动指引、预设流程、评分或分析。

- [原始卡片库](../src/_mock/_design-your-love.js)保留全部 108 张卡片的文字、ID、分类和颜色。`src/sections/love-design/data.js` 仅展开静态定义，坐标不写入卡片库。
- `tableState.js` 单独管理桌上卡片的 `cardId/x/y/rotation/zIndex`、`selectedDeck` 和剩余 `remainingOrder`。固定桌面尺寸为 2400 × 1600，卡片为 220 × 320；屏幕尺寸变化不重新排列卡片。
- 切换筛选只改变可抽取的牌堆。抽牌不会重复；洗牌仅打乱当前筛选内仍在牌堆的卡片；放回单张或全部收回把卡片追加到剩余牌序，重置恢复初始筛选和原始牌序。
- 工具栏提供「随机抽牌／按顺序抽牌」，默认随机从当前筛选的剩余卡片中等概率抽取，收回前不会重复。按顺序模式从当前剩余牌序的第一张抽取（洗牌会改变该顺序）。抽牌方式随牌桌保存，切换筛选、语言、刷新及重置牌桌时保留；旧版存档没有此设置时默认随机，已有摆牌不变。
- 页面继承全局主题、主题色、对比度、字体与方向设置；大屏「拉伸」切换内容限宽／铺满，逻辑桌面尺寸不变。RTL 只影响文字与工具栏，桌面仍以左上角为坐标原点。本页设置面板隐藏后台「布局」选项，其他路由不受影响。
- 桌面默认「选择」，粗指针设备默认「平移」，可在工具栏切换。选择工具在空白处框选，旋转后的外接矩形相交即选中（包括叠放卡片）。Shift 框选追加；Ctrl／Cmd 点击切换单张；点击已选卡片保留整组，点击未选卡片改为单选。点击空白或 Esc 清除选择。
- 拖动选中卡片会按统一位移移动整组，保留相对位置、角度和内部层级；边界按整组选区限制。平移工具可在空白或卡片表面拖动视野，卡片菜单按钮仍可点击。鼠标和触控共用 `useTableGestures.js`，包含边缘自动滚动、滚动偏移与取消恢复；指针取消／拖动时 Esc 恢复手势开始前的选择、位置与视野。
- 选中集合支持确认后收回、整组置顶／置底、六种边界对齐、横排／竖排／网格及取消选择。排列保留角度，按 y、x、ID 稳定排序，旋转外接框之间至少留 16px；网格优先采用数量平方根向上取整的列数，再寻找最接近的可容纳列数。空间不足时禁用并说明，不缩小卡片。整理允许与未选卡片重叠。
- 键盘聚焦牌桌时 Ctrl／Cmd + A 全选已抽出的卡片。聚焦卡片后方向键移动选中集合 10px，Shift + 方向键移动 40px，Enter／空格选择卡片，Shift + F10 或菜单按钮打开操作。没有吸附、分区或位置含义。
- 浏览器使用 `love-design-table`（版本 1）保存牌桌位置、角度、层级、筛选与剩余牌序。拖动完成时保存；取消拖动恢复原位置。恢复时校验每张卡片只存在于桌面或牌堆中一次，拒绝未知 ID、重复、缺失或越界数据。存储不可用时可继续使用，界面会提示。
- 旧版引导流程的存档不再读取。重置只影响牌桌，不清除系统语言或其他应用数据。
- 双语文案仍使用 [messages.json](../src/locales/messages.json)，分类显示使用 `domainLabel()`，切换语言保留牌桌状态。
- 选择、工具、选框与拖动预览仅保存在内存中，不写入卡片库或存档；刷新只恢复原有版本 1 牌桌数据。切换筛选保留选择，收回／重置移除失效选择。主题、语言与全屏尺寸变化不重新挂载或排列卡片。

验证命令：

```sh
npm run test:love-design
npm run test:i18n
npx eslint src/sections/love-design src/pages/LoveDesignPage.js src/components/settings/drawer/SettingsDrawer.js
npm run build
```

自动测试覆盖筛选、洗牌范围、无重复抽牌、旋转框选、追加／取消选择、整组移动与边界、鼠标／触控事件、滚动偏移、取消拖动、批量层级和收回、六种对齐、三种排列、空间不足、双语与全局设置切换、刷新恢复及存储异常。尺寸和全屏变化在 DOM 测试中模拟；实际触控手感、原生全屏、主题对比度、长文换行、菜单遮挡及桌面／手机视觉布局仍需可用浏览器验收。
